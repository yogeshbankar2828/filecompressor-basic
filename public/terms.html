Last updated: 17 September 2026

1. Service

PackZip is a file compression tool. You upload files through the website or the REST API. We return a ZIP or gzip file. Size reduction is not guaranteed. Already compressed media often stays about the same size.

2. Accounts

No account is required. Anyone who can reach the site can submit a job within the posted limits.

3. Acceptable use

You may only upload files you have the right to process. Do not use the service to store or distribute malware, or content that is illegal where you live. We may refuse or delete jobs that break these rules or that overload the server.

4. Limits

Default limits are 20 files and 50 MB per job, and a 60 minute download window. The operator can change these values in server configuration. Jobs that exceed limits are rejected.

5. Retention

Source files are removed after the archive is built. The archive is deleted when the job expires. Do not treat this site as backup storage.

6. Availability

The service is provided as is. We do not promise uptime, lossless results, or compatibility with every file format. If a job fails, the API returns an error message.
