Custom domain

Use your own hostname. Set DNS, TLS, and the two environment variables below.

DNS

Type Host Value
A @ Your server IPv4 address
AAAA @ Your server IPv6 address, if you have one
CNAME www Your apex domain

For GitHub Pages or similar static fronts, put the hostname in public/CNAME. This app is a Node server, so an A or AAAA record to the VPS is the usual path.

Environment

In .env:

SITE_URL=https://files.example.com

CUSTOM_DOMAIN=files.example.com

SITE_URL is used for canonical links, robots.txt, and the sitemap. CUSTOM_DOMAIN is added to CORS.

TLS and reverse proxy

Terminate HTTPS in nginx or Caddy, then proxy to 127.0.0.1:3000. A sample nginx server block is in deploy/nginx.example.conf. Set client_max_body_size a little above the upload cap.

Check

After DNS and TLS work, open /api/v1/config. You should see your domain in siteUrl and customDomain.
